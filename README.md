# SlotBot

Windows 下的 VRChat LuraSlot 桌面自动化辅助工具。左侧导航 + 「定位设置 / 参数设置 / 运行」三页卡片式布局（页内滚动、滚轮支持），整合 LuraSlot 1005 的识别与工具功能。

## 主要功能

- 固定坐标或图像模板定位：投币 → 下注 → 拉杆 → 三个停止按钮 → 循环。
- 快速投币：坐标模式每批只移动一次，随后按投币间隔连续点击。
- 数字辅助补币：可靠确认余额不足一注时提前补币；读不清时继续抽奖和设定的空转流程，同时继续识别。
- 运行期间保持亮屏、阻止自动睡眠；结束后释放 Windows 电源请求。
- 最长运行时间、延迟开始、指定开始和停止时间。
- F12 / End 急停、停止按钮及鼠标左上角急停。
- 数字样本、模板管理、配置方案、日志导出和 DPI 诊断。

## 环境与源码启动

使用 Windows 10 / 11、64 位 Python 3.11 或 3.12（含 Tkinter）。先安装 [Python](https://www.python.org/downloads/windows/)，然后在仓库目录运行：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_slotbot.py
```

如果使用 Python 3.12，把第一行的 `-3.11` 换为 `-3.12`。也可以依次双击 `install.bat`、`start.bat`。

仓库不提供个人 `config.json`。首次启动使用默认参数，必须在界面中设置当前机器的坐标；`config.example.json` 仅供理解配置格式。坐标、Credit 区域、模板和视角必须对应当前屏幕分辨率及游戏画面。改变视角或分辨率后需重新校准。

## 初次设置

1. 在游戏中站到机器正面，固定视角，确保游戏窗口可见。
2. 在「1. 定位设置」记录投币处、MaxBet、拉杆和三个停止按钮。押 1 / 2 枚时还要记录 Bet 按钮。
3. 使用移动测试检查位置；需要数字辅助时框住完整的 Credit 面板，保留四边，不要框到 ChanceMeter 或钱包数字。
4. 在「2. 参数设置」设置投币数量、动作延时和空转次数。
5. 在「3. 运行」开始，先确认实际转轮和按钮确实动作，再长时间运行。F12 / End 可立即停止。

程序通过前台截图和鼠标键盘输入工作，游戏窗口必须保持可见和前台。切换焦点、锁屏或操作失败会停止输入。保持亮屏功能不能阻止手动锁屏、睡眠、合盖或关闭显示器。

## Credit 判断原则

默认 MaxBet 为 3 枚：

| 识别结果 | 行为 |
| --- | --- |
| 可靠确认 0 / 1 / 2 | 不足一次下注，提前进入补币 |
| 可靠确认足够一次下注 | 继续抽奖并跳过新投币，无需确定是 67 还是 99 |
| 未知、截断、模糊或不一致 | 继续正常抽奖和设定的空转，每局继续尝试识别；次数流程结束后再补币 |

押 1 / 2 枚时按对应的不足一注条件判断。数字未知本身不会成为停止运行的理由。

低币补币要求连续三张独立画面确认同一个低币值，间隔至少 80 毫秒；每张都要通过完整选区检查、直接七段识别和严格模板交叉验证。模板距离最多 0.05，与次优差至少 0.08。不能用模板单独救援或两帧多数票触发补币。

足够类别同样需要连续三帧确认，直接段码和模板共同排除不足一注。足够类别中的具体数值可以变化；这不会放宽低币误判保护。识别仍依赖画面质量，不承诺任意画面零误判。

「空转清币次数」是读不清时的回退次数。可靠确认仍够一注时继续抽，不因次数达到就强制再投币。一直未知时，在正常抽奖和设定空转结束后按设定数量补币。

日志中的投币事件、下注按钮事件和动作局数是程序发出的动作统计，不能证明游戏真实扣币、抽奖成功或钱包收益。本版本没有金钱条件停止或自动寻路。

## 定时与保活

「定时 / 保活」入口位于参数页和运行页。`最长运行分钟 = 0` 表示不限时；指定时间使用北京时间 `YYYY-MM-DD HH:MM`。保存设置后点击开始运行才会开始等待。

默认到时只停止脚本。高级设置还支持退出助手、正常关闭指定游戏、关机等完成动作；关机前有可取消倒计时。手动急停、取消或异常结束不会触发这些完成动作。定时等待要求程序一直打开，开始时重新自检。

## 回归检查

```powershell
.\.venv\Scripts\python.exe regression.py
.\.venv\Scripts\python.exe tests\real_bench.py
.\.venv\Scripts\python.exe tests\extreme_bench.py
.\.venv\Scripts\python.exe run_slotbot.py --ui-smoke
```

主回归覆盖未知数字继续抽奖、可靠低币保护、足够类别继续抽奖、快速投币、急停、定时和界面契约。回归测试隔离数据目录并模拟游戏输入、窗口激活和电源动作；`--ui-smoke` 只构建界面后退出，不发送游戏输入。

`tests\extreme_bench.py` 是**斜视角压力基准**：用七段数码管的伪 3D 渲染器（单应变换模拟转视角/倾斜 + 真机干扰链）在 175 个视角 × 0-9 上统计解码成绩，用来守住「站位偏了识别不崩」的底线。

公开仓库仅包含数字和按钮裁剪图，排除完整游戏截图。主回归共 103 项，其中 5 项依赖可选的完整画面夹具，在公开包中标记为跳过，其余 98 项均应通过。私下提供 `tests/seven_screen_1.png` 至 `seven_screen_3.png` 可运行全景相关测试；它们已被 Git 忽略，不要公开上传。

需要诊断截图链路时可执行 `run_slotbot.py --diag` 或 `--selftest`；这些选项会读取当前屏幕。

## 从源码打包 EXE

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe build.py
```

输出为 `dist\SlotBot\SlotBot.exe`。分发整个 `dist\SlotBot` 文件夹（包括 `_internal`、数字样本和模板），不要只拷贝 EXE。构建使用 [PyInstaller](https://pyinstaller.org/en/stable/usage.html)，直接从本仓库源码打包，不依赖旧合并 EXE 或本机历史环境路径。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `run_slotbot.py` | 统一启动入口 |
| `slotbot.py` | 基础引擎、图像定位、样本工具与应用组合 |
| `vision.py` | 七段识别、模板交叉验证与 Credit 类别判断 |
| `runtime_controls.py` | 补币策略、快速投币、保活和定时 |
| `original_ui.py` | 原版三标签页界面 |
| `original_features.py` | 后台任务、急停、配置与高级设置 |
| `regression*.py`、`tests/` | 回归与识别基准 |
